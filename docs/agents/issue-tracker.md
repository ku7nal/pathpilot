# Issue tracker: Local Markdown

Specs and tickets live under `.scratch/`.

- One feature per directory: `.scratch/<feature-slug>/`
- Spec: `.scratch/<feature-slug>/spec.md`
- Tickets: `.scratch/<feature-slug>/issues/<NN>-<slug>.md`, numbered from `01`
- Each ticket has a `Status:` line near the top; new tickets use `ready-for-agent`
- Add comments and conversation history under `## Comments`

When a skill says to publish to the tracker, create the requested file in the relevant `.scratch/` directory.
